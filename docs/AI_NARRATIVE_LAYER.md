# PHASE 3 — AI NARRATIVE & PERSONALIZATION LAYER SPECIFICATION

## 1. Executive Summary

Phase 3 establishes Gemini as a secondary, grounded editorial layer. Gemini is strictly prohibited from selecting, ranking, or altering products or match percentages. Product selection and scoring are 100% owned by the deterministic scoring engine.

---

## 2. Architectural Data Flow

```
QUIZ ANSWERS
    │
    ▼
CUSTOMER PREFERENCE PROFILE (10D Vector)
    │
    ▼
DETERMINISTIC SCORING ENGINE (Weighted Cosine Similarity)
    │
    ▼
TOP 3 REAL FRAGRANCES (Authoritative Dataset Records + Match Percentages)
    │
    ├───▶ [ GEMINI NARRATIVE LAYER ] ────────┐
    │     - System Prompt (Fragrance grounded)│
    │     - Strict Zod Schema Validation     │
    │     - ID sanitization & verification   │
    │     - 8s timeout with fallback         │
    │                                        │
    ▼                                        ▼
[ DETERMINISTIC RESULT ADAPTER ] ◀───────────┘
    │ (Merges Authoritative Catalog Facts + Editorial Story)
    ▼
FINAL RESULTS UI
```

---

## 3. Clear Division of Responsibilities

| Responsibility                        | Deterministic Scoring Engine |   Gemini Narrative Layer    |
| :------------------------------------ | :--------------------------: | :-------------------------: |
| Product Identification & Selection    |   **Authoritative (100%)**   |        _Prohibited_         |
| Product Ranking & Tie-Breaking        |   **Authoritative (100%)**   |        _Prohibited_         |
| Numerical Match Percentage            |   **Authoritative (100%)**   |        _Prohibited_         |
| Notes, Accords & Olfactive Facts      |   **Authoritative (100%)**   |        _Prohibited_         |
| Performance (Longevity / Sillage)     |   **Authoritative (100%)**   |        _Prohibited_         |
| Commercial Info (Brand, Price, Image) |   **Authoritative (100%)**   |        _Prohibited_         |
| Personalized "Why Match" Explanation  |      Fallback Baseline       | **Primary Personalization** |
| Evocative Editorial Atmosphere Story  |        Factual Backup        |   **Primary Storyteller**   |
| Poetic 2-5 Word Aura Tagline          |      Default Family Tag      | **Primary Creative Label**  |

---

## 4. Grounding & Anti-Hallucination Guardrails

1. **Explicit Prompt Instructions**: Gemini is provided only with the customer's answers and the factual notes/accords of the deterministic Top 3 items.
2. **Strict Zod Output Validation**: Output is validated against `GeminiNarrativeResponseSchema`.
3. **ID Sanitization & Authorization**: Every returned narrative is checked against `authoritativeIds = Set(topProducts.map(p => p.fragranceId))`. Any rogue or invented IDs are discarded.
4. **Factual Immutability**: All product metadata (name, notes, house, match_percent) are injected directly from the database record during final formatting.

---

## 5. Resilient Fallback Strategy

$$\text{Gemini Failure} \neq \text{Recommendation Failure}$$

If any of the following occur:

- `LOVABLE_API_KEY` is missing or invalid
- Gemini returns malformed / unparsable JSON
- Network timeout (> 8000ms)
- Gateway error (4xx / 5xx)

The application automatically falls back to deterministic, fragrance-grounded narratives generated by `buildAllFallbackNarratives()`. Recommendations and match percentages remain intact.
